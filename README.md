# AGENTIC AI

Proyecto editorial para preparar una guía en español sobre IA agéntica.
La fase actual establece el flujo de trabajo, la trazabilidad de fuentes
y los criterios de calidad. La traducción y la incorporación del PDF
original quedan fuera de esta fase.

## Validación local

Desde la raíz de una copia Git, ejecuta `make check`. Requiere Make,
Git y un intérprete POSIX. Revisa también el diff y los enlaces que
afecte el cambio antes de integrarlo.

Consulta la [atribución](ATTRIBUTION.md), el [aviso de derechos](LICENSE)
y el [registro de cambios](CHANGELOG.md).
